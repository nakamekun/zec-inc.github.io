# zec-inc.jp サイト改善 指示書

対象リポジトリ: `zec-inc.github.io`(GitHub Pages / 独自ドメイン `zec-inc.jp`)

## 運用方針(最重要・全タスクに優先)

当面は **ロープロファイル運用** とする。サイトの品質・整合性は改善するが、
**運営者個人の特定につながる情報の露出を一切増やさない。**

### 禁止事項(このフェーズでは絶対にやらない)

- 代表者名・個人名の掲載
- 所在地の詳細化(番地・建物名)。「東京都江東区」のままとする
- 電話番号の掲載
- 個人アカウントに紐づく外部サービスの導入(Google フォーム、Calendly、Analytics 等)
- 個人の SNS・ブログ・他プロジェクトへのリンク追加
- `Organization` の JSON-LD 構造化データ追加、被リンク獲得などの積極的な SEO 施策
- プレスリリース・ニュースセクションの新設

既存の GitHub リンク(`github.com/nakamekun/app-store-monitor`)は現状維持。新たな個人アカウントへのリンクは追加しない。

## フェーズ1: 今回実施するタスク

### 1. トップページ(`index.html`)のフッター整備

- フッターに `privacy.html`(プライバシーポリシー)と `support.html`(サポート)へのリンクを追加(現状 `/apps/` のみ)
- コピーライトを `© 2026 ZEC Inc.` に更新(`privacy.html` / `support.html` は年の記載自体がないので `© 2026 ZEC Inc.` に統一)

### 2. プライバシーポリシーの日本語化(`privacy.html`)

- サイト本体が日本語なのにポリシーが英語のみ・アプリ向け汎用文になっているのを解消する
- 日本語を主、既存英語文を従とした日英併記に再構成
- 記載する事業者情報は「合同会社ゼク(ZEC Inc.)」の社名と `info@zec-inc.jp` 窓口のみ。**個人名・詳細住所は書かない**
- 内容: 基本方針/取得する情報(アプリはローカル保存が原則)/利用目的/第三者提供しない旨/お問い合わせ窓口/制定日(2026年7月)
- `lang="ja"` に変更し、トップページへ戻るリンクを追加

### 3. トップページの head 整備

- `meta name="description"` を追加(社名+事業内容の要約、120字程度、日本語)
- `<link rel="canonical" href="https://zec-inc.jp/">` を追加
- OGP を追加: `og:title` / `og:description` / `og:url` / `og:site_name` / `og:type=website`。`og:image` は新規画像を作らず省略してよい
- ※ 構造化データ(JSON-LD)は追加しない(禁止事項参照)

### 4. favicon の追加

- テキストベースのシンプルな SVG favicon(例: ヘッダー色 `#2c3e50` 背景に白の「Z」)を `/favicon.svg` として作成
- 全ページ共通で `<link rel="icon">` を追加(既存アプリ詳細ページはビルドスクリプト `scripts/update_apps_page.py` のテンプレート側も更新すること)
- 会社ロゴ画像の新規作成・外部画像の利用はしない

### 5. カスタム 404 ページ(`404.html`)の新規作成

- サイト共通デザインで作成し、トップ(`/`)とアプリ一覧(`/apps/`)への導線を置く
- 日本語主体、英語一行併記

### 6. 言語・フォント・デザインの統一

- 日本語ページのフォントスタックを統一:
  `-apple-system, BlinkMacSystemFont, "Hiragino Sans", "Noto Sans JP", "Segoe UI", sans-serif`
  (トップの `"Segoe UI", sans-serif` は日本語表示に不適)
- `support.html` を日本語主体に変更(`lang="ja"`、日英併記可)し、トップへ戻るリンクを追加
- `apps/` 配下は英語ページとして現状維持でよい

### 7. 問い合わせ表記の統一(`index.html`)

- トップの `info@(アットマーク)zec-inc.jp` は難読化方針を維持しつつ、コピーしやすいよう表記を整える(例: `info [at] zec-inc.jp` 等に揃える、または現状維持)
- **問い合わせフォームは導入しない**(禁止事項参照)。`support.html` の `mailto:` は現状維持

### 8. 共通 CSS への切り出し(任意・余力があれば)

- 各ページにインライン重複している CSS を `/assets/site.css` に集約し、`:root` のカラートークンを統一
- ただしアプリ詳細ページは自動生成のため、テンプレート(`scripts/update_apps_page.py`)との整合を崩さない範囲で行うこと。リスクが大きければトップ・privacy・support・404 の4ページのみでよい

### 9. `sitemap.xml` の lastmod 更新

- 全 URL が `2026-06-15` 固定になっている。今回変更したページの `lastmod` を実際の更新日に修正

### 検証

- `python3 scripts/validate_apps_pages.py` が通ること
- 変更した各ページをブラウザで開き、表示崩れ・リンク切れがないこと
- `git diff` に意図しない自動生成ファイルの変更が混ざっていないこと
