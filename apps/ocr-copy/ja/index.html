OCR Copy

カメラ・ライブスキャン・写真から文字を読み取ってすぐコピー。認識はすべて端末内で行われ、保存したテキストは後からもコピーできます。

概要

OCR Copyは、目の前の文字をすばやくコピーするためのローカル完結型OCRアプリです。ライブスキャン、カメラ撮影、写真ライブラリの画像から、Apple Visionによる端末内の文字認識でテキストを読み取り、その場でコピーできます。レシート、本、荷物のラベル、スクリーンショット、看板など、日常の文字に使えます。

重いドキュメント管理アプリやクラウドOCRサービスではなく、「読み取って、コピーして、終わり」という小さな仕事に絞りました。認識結果が完璧でないときは行単位で修正・削除でき、元のOCR結果はそのまま保持されます。信頼度や文字位置は、スコアを押し付けるのではなく、必要な人だけが見られる詳細情報として用意しています。

保存したテキストは端末内に残り、後から開いてもう一度コピーできます。自動判定でうまく読めないときは、日本語+英語、韓国語+英語、中国語+英語、欧州言語などのOCR言語モードを選べ、高精度と高速の認識切り替えもできます。

こんな方に

  • レシートや荷物、本、紙の書類の文字を打ち直すことが多い方
  • スクリーンショットや写真の文字を、クラウドサービスを使わずに取り出したい方
  • 多言語の文字を扱うため、OCRの対象言語を選びたい方
  • 写真やテキストをサーバーに送りたくない、プライバシー重視の方

主な機能

  • ライブスキャン: カメラをかざしてリアルタイムに文字を取得
  • カメラ撮影や写真ライブラリの画像からのOCR
  • Apple Visionによる端末内の文字認識（サーバー不使用）
  • 元のOCR結果を保持したまま、行単位で修正・削除
  • 認識したテキストを端末内に保存し、後からもう一度コピー
  • OCR言語モード（自動 / 日本語+英語 / 英語 / 韓国語+英語 / 簡体字・繁体字中国語+英語 / 欧州言語）と、信頼度・文字位置の詳細表示

使い方

  1. アプリを開き、ライブスキャン・カメラ撮影・写真ライブラリのいずれかを選びます。
  2. 端末内で文字認識が実行されるのを待ちます。
  3. 認識されたテキストを1タップでコピーします。
  4. 必要なら行をタップして修正・削除します。元のOCR結果は保持されます。
  5. テキストを保存しておくと、ホーム画面から後で開いて再コピーできます。
  6. うまく読み取れないときは、設定でOCR言語モードや認識精度を変更します。

プライバシー

OCRはApple Visionを使ってすべて端末内で実行されます。写真、認識テキスト、行の修正内容、信頼度、サムネイルはアプリ内にローカル保存され、外部サーバーへ送信されることはありません。アカウント・トラッキング・解析もなく、テキストの共有はiOSの共有シートから自分で操作したときだけ行われます。

スクリーンショット

よくある質問

OCR Copyは無料ですか？

はい。無料で、サブスクリプションやアプリ内の課金要素はありません。最新の価格はApp Storeでご確認ください。

写真や読み取ったテキストはアップロードされますか？

いいえ。文字認識は端末内のApple Visionで実行され、写真・テキスト・修正内容はローカルに保存されます。外部通信・アカウント・トラッキングや解析SDKはありません。

どの言語を読み取れますか？

自動判定に加えて、日本語+英語、英語、韓国語+英語、簡体字中国語+英語、繁体字中国語+英語、欧州言語のモードを選べます。高精度と高速の認識切り替えもできます。

認識結果に間違いがあったらどうなりますか？

行単位で修正・削除できます。元のOCR結果は保持されるため、修正しても元の読み取り内容は失われません。詳細表示を有効にすると、信頼度が低い行が確認対象として示されます。

手書きや縦書きの日本語も読めますか？

現在のバージョンは、写真やカメラに写った印刷文字が主な対象です。縦書きの日本語や複雑なページレイアウトは、主な対応範囲ではありません。
