簡介

PinLog 是一款讓你稍後重溫文字和連結的備忘錄 App。把內容儲存為 Pin，之後它會主動再次出現。儲存只需片刻，記住它的事交給 App。

■ 先儲存下來 • 點一下 + 撰寫並儲存 • 在其他 App 中點一下分享按鈕，選擇 PinLog 儲存文字或連結 • 使用「從剪貼簿儲存」儲存已拷貝的文字 • 對 Siri 說「儲存 Pin 到 PinLog」，也可以透過「控制中心」或「捷徑」App 撰寫 • 使用語音輸入，或匯入文字、Markdown 和 JSON 檔案 • 含連結的 Pin 會顯示網頁標題

■ 讓它再次出現 • 儲存了幾天或許久未查看的 Pin，會再次出現在首頁和小工具中 • 點一下 Pin 的鈴鐺，設定今晚、明早、週末或自選日期與時間的提醒 • 在設定中開啟「每天提醒一個 Pin」，即可在指定時間收到一個 Pin
