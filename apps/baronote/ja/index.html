BaroNote

iPhoneの気圧センサーで今の気圧と変化の傾向を確認し、そのときの体調・気分をメモできるアプリ。記録はすべて端末内に保存されます。

概要

BaroNoteは、iPhoneの内蔵気圧センサーで測った「今の気圧」と、そのときの体調・気分を1画面で記録するシンプルな気圧計＆メモアプリです。気圧が上がっているのか、横ばいか、下がっているのかの傾向も合わせて表示します。

多くの天気アプリでは、気圧の数字は予報や広告の奥に埋もれがちです。BaroNoteはその逆で、実測値とシンプルな傾向、そして軽い記録だけに絞りました。予報はせず、アカウントも追跡も広告もサーバーへのアップロードもなく、記録は端末の中にだけ残ります。医療的な助言・診断・治療・予報は行わず、あくまで個人の記録のためのアプリです。

履歴では、記録までの6時間の気圧の変化を各記録のそばに並べて表示します（原因の判断はしません）。ヘルスケア連携は任意で、初期設定ではオフです。オンにしたときだけ、頭痛・疲れと気分（iOS 18以降）をAppleヘルスケアにも記録します。ヘルスケアのデータは読み込みません。

ホーム画面・ロック画面のウィジェットで現在の気圧と傾向をひと目で確認でき、アプリを開かなくても気圧をチェックできます。

こんな方に

  • 天気や気圧が変わるときの自分の調子をメモしておきたい方
  • 本格的な天気アプリを開かずに、気圧の実測値だけをシンプルに見たい方
  • 体調・気分のかんたんな記録を日々つけている方
  • 記録をクラウドに出したくない、プライバシー重視の方
  • ホーム画面やロック画面で気圧を確認したいウィジェット派の方

主な機能

  • iPhoneの気圧センサーによる実測値の表示（対応機種）
  • 上昇・横ばい・下降の傾向表示
  • 気分・体調（よい/ふつう/よくない）、頭痛・眠い・疲れなどの症状タグ、ひとことメモの記録
  • 記録のそばに、記録までの6時間の気圧の変化を並べて見られる履歴
  • 任意のAppleヘルスケア連携（初期設定はオフ）。頭痛・疲れと、iOS 18以降は気分を書き込みます。読み込みはしません
  • hPa / mb / inHg / mmHg の単位切り替え
  • ホーム画面ウィジェットとロック画面ウィジェット
  • 記録は端末内に保存。設定から全データ削除も可能

使い方

  1. アプリを開くと、ホーム画面に現在の気圧と傾向が表示されます。
  2. 記録ボタンをタップして、今日の記録を追加します。
  3. 気分・体調（よい/ふつう/よくない）を選び、症状タグを付け、必要ならメモを入力します。
  4. 履歴で過去の記録と気圧の変化を見返します。
  5. 必要に応じて、設定で気圧の単位（hPa / mb / inHg / mmHg）を変更します。
  6. ウィジェットをホーム画面やロック画面に追加すると、アプリを開かずに気圧を確認できます。

プライバシー

気圧の記録、体調・気分のメモ、症状タグ、設定はすべて端末内に保存され、サーバーへアップロードされることはありません。アカウント・クラウド同期・トラッキング・広告・解析SDKもありません。ウィジェットは、アプリとウィジェットの間だけで共有する端末内のデータを読み取ります。ヘルスケア連携は任意で初期設定はオフ。オンにしても書き込むのは対応項目（頭痛・疲れ、iOS 18以降は気分）だけで、ヘルスケアのデータは読み込みません。設定からすべてのデータをいつでも削除できます。

スクリーンショット

よくある質問

BaroNoteは無料ですか？

はい。無料で、広告もありません。最新の価格はApp Storeでご確認ください。

記録したデータはどこに保存されますか？

記録は端末内に保存されます。アカウント・クラウド同期・サーバーへのアップロード・トラッキングはなく、設定からすべてのデータを削除することもできます。

どのiPhoneでも使えますか？

気圧の表示にはiPhone内蔵の気圧センサーを使用します。センサーを搭載していない端末では、測定できない旨が表示されます。iOS 17以降が必要です。

ウィジェットはありますか？

はい。ホーム画面とロック画面のウィジェットで、現在の気圧と傾向を確認できます。

天気予報や頭痛の予測はできますか？

いいえ。表示するのは実測した気圧と、上昇・横ばい・下降のシンプルな傾向だけです。予報や診断、医療的な助言は行いません。個人の記録と振り返りのためのアプリです。

記録にはどんな項目がありますか？

気分と体調（よい/ふつう/よくない）、頭痛・眠い・疲れ・集中できない・肩こりなどの症状タグ、ひとことメモを記録できます。そのときの気圧も一緒に保存されます。

Appleヘルスケアと連携できますか？

任意で連携できます。初期設定はオフです。オンにすると、頭痛と疲れ、iOS 18以降は気分をヘルスケアに書き込みます。ヘルスケアのデータは読み込まず、眠気・集中できない・肩こり・気圧・メモは書き込みません。
