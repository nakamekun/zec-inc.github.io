かず鍛冶 - 毎日1問の数字パズル

スクリーンショット

概要

かず鍛冶は、1日1問だけの数字パズルです。毎日新しい問題が1問届き、6つの数字を足す・引く・掛ける・割るで組み合わせて目標の数を作ります。数字を2つ選んで演算を選ぶと新しい数字が生まれるので、できるだけ少ない手数で目標にたどり着きましょう。

問題は毎日1問だけで、世界中のプレイヤーが同じ問題に挑戦します。だらだら遊び続けるゲームではなく、短い「毎日の頭の体操」として続けられる設計です。「パー」は理論上の最少手数。解けたあとも「パーで解けるか」というもうひと粘りの楽しみがあります。解いたあとは、任意のGame Centerで「きょうのランキング」の順位（2000点満点）を確かめたり、ほかの作り方を探して今日の称号を上げたりできます。連続記録やパー達成数の記録、ネタバレなしの結果シェアが習慣を後押しします。

惜しくても大丈夫。いつでも「ここで終える」ことができ、目標との差が10以内なら星2つ、25以内なら星1つ、星がつけば連続記録は続きます。終えたあとは答えの例を見られ、今日の問題を終えると前の日付の問題も練習できます。ホーム画面ウィジェット（小・中サイズ）では、解く前は今日の目標の数を、クリア後は結果をひと目で確認でき、任意の1日1回リマインダーにも対応します。アプリとウィジェットはストアと同じ13言語に対応しています。

主な機能

  • 毎日1問の新しい問題。世界中のプレイヤーが同じ問題に挑戦
  • 数字を2つ選んで+−×÷で合成する「フォージ」操作。やり直し・リセットにも対応
  • 理論上の最少手数「パー」を表示。同じ手数でのクリアに挑戦できる
  • Game Centerの「今日のフォージ」ランキング。2000点満点で、パー超過は1手ごとに−200点、時間は1秒ごとに−1点（20分で打ち切り）。サインインは任意
  • いつでも「ここで終える」: 目標との差が10以内なら星2つ、25以内なら星1つで、連続記録は続きます。終えたあとは答えの例を表示
  • 解いたあとにほかの作り方を探すと、今日の称号が上がります（見習い → 職人 → 名工 → 刀匠）
  • 今日の問題を終えると、前の日付の問題を端末内で練習できます。順位・連続・称号・統計には数えません
  • クリア日数・現在の連続記録・最長連続記録・パー達成数を記録
  • 問題番号・手数・連続記録だけを載せたネタバレなしのシェアテキスト
  • 今日の目標やクリア結果を表示するホーム画面ウィジェット（小・中）
  • 通知は任意の1日1回リマインダーのみ。アカウント登録不要・広告なし・トラッキングなしで、アプリとウィジェットは13言語に対応

こんな方に

  • WordleやNYT Digitsのようなデイリーパズルが好きで、数字版を探している方
  • 朝のコーヒータイムや通勤時間に、短くて手応えのある計算トレーニングをしたい方
  • ただ解くだけでなく、最少手数の解を追いかけたいパズル好きの方
  • 連続記録を途切れさせずに積み上げるのが好きな方
  • 広告なし・アカウント不要・トラッキングなしの脳トレアプリを求めている方

使い方

  1. アプリを開くと、今日の問題がすぐに表示されます。オンボーディングもメニュー画面もありません。
  2. 数字タイルを2つ選び、演算を選んで新しい数字を作ります。
  3. 目標の数になるまで組み合わせを続けます。間違えたらやり直し・リセットで戻れます。届かないときも、いつでも終えて星を獲得できます。
  4. 理論上の最少手数「パー」と同じ手数でのクリアに挑戦してみましょう。
  5. 解いたら「きょうのランキング」で順位を確認（Game Centerのサインインは任意）し、ほかの作り方を探したり、結果をネタバレなしのテキストでシェアしたりできます。
  6. 翌日また新しい問題に挑戦して連続記録をつなぎましょう。ウィジェットで新しい目標の数がひと目でわかります。

アカウント登録は不要で、広告もトラッキングもありません。クリア日数・連続記録・設定などの記録は端末内にのみ保存され（ウィジェットとの共有も端末内のApp Group経由）、iCloud同期や独自のサーバーはありません。Game Centerへのサインインは任意で、サインインした場合にのみ、きょうのランキング用に当日のスコアがGame Centerへ送られます。それ以外はサインインなしで使えます。リマインダーは任意のローカル通知です。

よくある質問

かず鍛冶は無料ですか？

はい。広告なし・アプリ内課金なしで無料です。価格は変わる可能性があるため、最新の情報はApp Storeでご確認ください。

毎日の問題はどういう仕組みですか？

問題は日付から生成され、毎日1問だけ。世界中のプレイヤーが同じ問題に挑戦します。6つの数字を+−×÷で組み合わせて目標の数を作ります。

「パー」とは何ですか？

その日の問題を解くのに必要な理論上の最少手数です。解くだけでなくパーと同じ手数でクリアできるかが本当の挑戦で、パー達成数はアプリが記録してくれます。

きょうのランキングはどういう仕組みですか？

今日の問題を解くと、Game Centerの「今日のフォージ」で「今日 N位 / M人」と表示されます。2000点満点で、パー超過は1手ごとに−200点、時間は1秒ごとに−1点（20分で打ち切り）です。サインインは任意で、しなくても全機能を使えます。

目標に届かないときはどうなりますか？

いつでも「ここで終える」ことができます。目標との差が10以内なら星2つ、25以内なら星1つで、星がつけば連続記録は続きます。終えたあとは答えの例を見られます。

過去の問題も遊べますか？

はい。今日の問題を終えると、前の日付の問題を端末内で練習できます。順位・連続・称号・統計には数えません。

オフラインでも遊べますか？

問題は端末内で生成されるので、オフラインでも遊べます。通信が必要なのは、任意のGame Centerランキングだけです。

ウィジェットはありますか？

はい、小・中サイズがあります。解く前は今日の目標の数を、解いたあとは結果を表示し、日付が変わると次の問題に更新されます。

アプリはどんなデータを集めますか？

アカウントも広告もトラッキングもありません。連続記録や結果は端末内にのみ保存されます。Game Centerにサインインした場合にのみ、ランキング用に当日のスコアがGame Centerへ送られます。

通知は届きますか？

任意の1日1回リマインダーをオンにした場合のみ届きます。通知なしでも全機能を使えます。
