소개

숫자 대장간는 하루에 한 문제만 나오는 숫자 퍼즐이에요. 숫자 여섯 개를 + - x /로 조합해서 목표 숫자를 만들어 보세요.

게임 방법 - 숫자 두 개와 연산을 골라 새로운 숫자를 만들어요. - 되도록 적은 횟수로 목표 숫자에 도달해 보세요. - Par는 이론상 최소 횟수예요. 같은 횟수로 풀 수 있을까요?

하루 한 문제 - 모두가 같은 날, 같은 문제에 도전해요. - 퍼즐을 푼 날 수, 현재 연속 기록, 최고 연속 기록, Par 달성 수를 기록해요. - 결과는 문제 내용이 드러나지 않는 텍스트로 공유할 수 있어요.
