Overview

DoneToday: Daily Log is a one-tap habit tracker for a single daily task. Open the app (or just glance at the widget), tap once to mark today done, and the calendar keeps a simple visual history of your progress so you can see the habit build day by day.

It is deliberately not a task manager. There are no projects, no team features, and no cloud setup — the whole app is built around the one action that matters: did you do your thing today? That focus keeps it fast enough to actually use every day.

The Home Screen widget is interactive: you can toggle today's completion directly from the widget without opening the app. Optional reminder notifications include a Done action, and reminders are automatically skipped on days you have already completed.

Who It Is For

  • People trying to build one daily habit, like exercise, journaling, or language practice
  • Anyone who abandons full-featured habit apps because they take too long to log
  • Users who want their streak visible on the Home Screen at a glance
  • People who want a reminder that knows to stay quiet once the task is done

Main Features

  • One-tap done / undo for today's task
  • Calendar view showing your completion history
  • Interactive Home Screen widget — mark today done without opening the app
  • Optional local reminder notifications with a Done action
  • Reminders automatically skipped on days already completed
  • Data stored locally on your device

How to Use

  1. Open DoneToday and decide the one daily task you want to track.
  2. Tap once to mark today as done (tap again to undo).
  3. Open the calendar view to review which days you completed.
  4. Add the Home Screen widget to see and toggle today's status without opening the app.
  5. Optionally turn on a daily reminder — it is skipped automatically on days you have already finished.

FAQ

Is DoneToday free?

Yes. The app is free to download and has no in-app purchases. App Store pricing can change, so check the listing for current details.

Where is my data stored?

On your device. DoneToday has no account and no server sync — your completion history stays local. See the App Store privacy label for the full summary.

Does DoneToday have a widget?

Yes, and it is interactive: you can mark today done (or undo it) directly from the Home Screen widget without opening the app.

Can it remind me every day?

Yes. You can enable an optional local notification reminder, which includes a Done action. On days you have already completed the task, the reminder is skipped.

Can I track multiple habits?

The app focuses on a single daily task by design, which keeps logging down to one tap. It is intentionally not a multi-list task manager.

Does it work offline?

Yes. Everything is stored locally on the device, so no internet connection is needed to log or review your history.
