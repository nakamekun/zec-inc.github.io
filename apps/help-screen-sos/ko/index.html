소개

도움 화면 SOS는 말하기 어렵거나 현지 언어로 설명하기 어려울 때, 휴대폰 화면을 보여 주어 주변 사람에게 도움을 요청하는 보조 앱입니다.

한국어 환경에서는 대중교통이나 여행 중의 불안, 괴롭힘, 몸이 좋지 않은 상황 등에서 사용할 수 있는 짧고 큰 SOS 문구를 표시합니다. 표시 언어는 사용자가 직접 선택할 수 있으며, 한국어, 영어, 일본어, 중국어 간체, 중국어 번체 문구를 지원합니다.

주요 기능: - 전체 화면 SOS 문구 표시 - 상황 선택 - 표시 언어 수동 선택 - 말할 수 없음, 말하기 어려움, 현지 언어를 못함 안내 표시 - 영어 병기 옵션 - 보조 알람, 진동, 화면 깜박임 - 홈 화면 및 잠금 화면 위젯 - 제어 센터, 단축어 및 동작 버튼용 동작 - 모든 기능은 기기 안에서 동작
